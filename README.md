# Sentiment Analysis using RNN

## Overview

This project focuses on **Sentiment Analysis using Deep Learning and Recurrent Neural Networks (RNN)**.

The model analyzes text and predicts the sentiment expressed in the given text, such as **positive or negative**.

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Natural Language Processing (NLP)
* Recurrent Neural Networks (RNN)

## Project Workflow

1. Load the sentiment dataset.
2. Clean and preprocess the text data.
3. Tokenize the text.
4. Convert text into numerical sequences.
5. Prepare the data for training.
6. Build an RNN-based deep learning model.
7. Train the model.
8. Evaluate the model performance.
9. Test the model with new text.
10. Predict the sentiment.

## Model

The project uses a **Recurrent Neural Network (RNN)** to learn patterns from text sequences and classify their sentiment.

For example:

```text
Input: "I really enjoyed this movie."

Prediction: Positive
```
